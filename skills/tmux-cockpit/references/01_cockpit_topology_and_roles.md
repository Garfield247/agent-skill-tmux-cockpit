# 赛博三联屏战斗舱拓扑与窗格职能 (Cockpit Topology & Roles)

## 1. 战术三联屏战斗舱拓扑治理 (The Cockpit Topology)

三联屏由 `agy-dev` 黄金启动器初始化并保持幂等：

```text
+-------------------+-------------------+
|   左上：观测台    |                   |
| (日志/测试/压测)  |     右边：agy     |
|    [高度 35%]     |    (AI 架构师)    |
|   ($OBS_PANE)     |                   |
+-------------------+  🔥 主对话交互舱  |
|   左下：用户工作区|    (默认光标聚焦) |
|  (留白终端 / nvim)|                   |
|    [高度 65%]     |    [宽度 50%]     |
+-------------------+-------------------+
```

---

## 2. 窗格职能与契约 (Pane Roles & Environment Contracts)

### 2.1 右侧主舱 (`agy`)
- **职能**：AI 架构师主交互界面。承担需求对齐、架构设计、原子代码编写与决策收口；
- **红线**：严禁在此窗格中直接运行长滚屏或阻塞性服务，杜绝垃圾 Token 污染上下文。

### 2.2 左上观测台 (`AGY_OBSERVER_PANE`)
- **职能**：动态外部输出终端。专门承载 `go test`、`pytest`、`stress_tester` 压测机器人、Docker 构建、微服务日志跟踪等高信息密度输出；
- **环境变量**：宿主环境通过 `tmux show-environment AGY_OBSERVER_PANE` 导出窗格 ID。

### 2.3 左下工作区 (User Pane)
- **职能**：用户专属代码与 CLI 主刀区（默认留空终端，或 `-nv` 启动 Neovim），供用户自由发挥；
- **红线**：Agent 绝不侵占或向其发送未经授权的指令。
